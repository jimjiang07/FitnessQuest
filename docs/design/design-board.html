Fitness Quest · design board · v0.1

Press start.
The coach does the rest.

A no-login web app for the 4-day Spine Rehab split. Pick a day, press start, and a voice coach calls every exercise, set, rest and side switch, one after another, the way an F45 or Fitstop class runs. No accounts and no tracking. Each screen is colour-coded by phase so you can read it from across the room.

01 · User flow

Two taps to start, then hands-free

Home and day detail are the only screens you browse. From Start on, the player runs a fixed list of steps. Timed steps move on by themselves; rep sets wait for you to tap Done, then rest starts by itself. You can pause from any player screen.

02 · Main layout · iPhone Duo open, landscape

Two halves, split at the fold

Opened flat and held sideways, the inner screen (about 890 × 626 pt) is like an open book: the fold runs top to bottom down the middle, and each half is about the size of the outer screen. Every workout screen uses that split the same way. The left half is now: the exercise, the timer or rep target, and Done. The right half is context: where you are, what’s next, the coach’s line and the controls. A 28 pt gap covers the fold, so no text or button sits on it.

04 · Standard phone

The same eight screens on a normal iPhone

Big type for reading from a mat two metres away. One primary action per screen, sized for sweaty thumbs. Dark by default to save battery and reduce glare.

05 · iPhone Duo · other ways to hold it

Closed, or half-folded upright

The app picks a layout from the screen’s size and orientation, so the same rules work on any phone or tablet. Landscape-open is the one designed first; these are the fallbacks.

Book · main

  • Landscape, 800 pt+ wide
  • Duo inner screen sideways (≈890 × 626). Fold runs top to bottom: left half is now, right half is context.

Compact

  • Under 440 pt wide
  • Standard iPhones. Section 03.

Short-wide

  • 440–599 pt wide, under 720 pt tall
  • Duo outer screen (≈466 × 678). Ring and up-next sit side by side.

Tabletop

  • 600 pt+ wide, portrait
  • Duo inner screen upright (≈626 × 890). Fold runs across the middle: timer on top, controls on the bottom.
06 · Voice coach

What the coach says, and when

Every line comes from a small set of templates, filled in from the plan data and recorded ahead of time as audio clips, the same way HeroQuest does it. Beeps come from Web Audio so they’re instant. Example: Superset A on Day 2.

07 · How it’s built

Same stack as HeroQuest

Stack

  • Vue 3 + Vite + TypeScript, Pinia, Vue Router (hash)
  • Static site on GitHub Pages. No backend, no login, no analytics
  • Vitest for the step engine, Playwright for E2E with a fake clock
  • Self-hosted fonts (@fontsource), no CDN scripts

Plan → steps

  • The plan is written in data/plan.ts: days → blocks → exercises
  • A pure buildSteps(day) turns it into a flat list of steps: ready, work, rest, switch, transition
  • The player just walks that list. Back and skip only move an index
  • Timers run off real timestamps, so they stay accurate if the tab sleeps

Audio

  • npm run voice records every line with edge-tts (an en-AU coach voice) into public/voice/
  • If a clip is missing, the device’s own voice (speechSynthesis) reads it
  • Web Audio beeps; the Start tap unlocks audio on iOS
  • Your music keeps playing underneath. Web apps can’t lower its volume

Phone friendly

  • Wake Lock keeps the screen on during a workout
  • Media Session shows the current exercise on the lock screen
  • Installable PWA with offline cache, so it works in a gym with no signal
  • localStorage keeps only settings and the next day number
  • iPhone Duo: landscape-open is the main layout; layout picked from width, height and orientation, and the fold is a 28 pt gutter. Uses the Viewport Segments API where Safari supports it
